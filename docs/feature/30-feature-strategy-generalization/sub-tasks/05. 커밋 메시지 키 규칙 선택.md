# 05. 커밋 메시지 > 키 규칙 선택 (스토리 / 스토리+하위)

## 목표
커밋 키에 `#`를 쓰지 않고, 스토리 시작 시점에 `[스토리][하위] 메시지`와 `[스토리] 메시지` 중 하나를 고를 수 있게 한다.

## 범위 (In)
- `feature-strategy` 9단계에 커밋 키 규칙 추가: 스토리 시작 시점에 선택, 결정 기록에 적기, `#` 금지
- 스토리는 이슈 번호 또는 트래커 키, 하위는 만든 하위 이슈 번호(없으면 로드맵 번호)
- 하위작업에 속하지 않는 커밋은 `[스토리] 메시지`, 트래커가 없으면 `[NN] 메시지`
- 질문 라운드 체크리스트, Phase C 문구, GitHub 운영 메모, 본문 템플릿 `## 커밋` 문구 정리

- 버전은 올리지 않음(1.4.7 유지)
